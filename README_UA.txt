КАЛЬКУЛЯТОР ДБЖ — Android-проєкт, версія 0.1.0

Що це:
Android-оболонка, яка відкриває вбудований калькулятор з assets/index.html.
Інтернет-дозволи не потрібні; калькулятор працює офлайн.

Як отримати APK без встановлення Android Studio на своєму ПК:
1. Розпакуйте цей ZIP.
2. Створіть приватний або особистий репозиторій на GitHub і завантажте в нього всі файли проєкту.
3. Відкрийте вкладку Actions.
4. Запустіть workflow "Build Android APK" (Run workflow).
5. Після завершення відкрийте результат запуску й завантажте artifact "kalkuliator-dbzh-apk".
6. Розпакуйте artifact ZIP — усередині буде app-debug.apk.
7. Перенесіть APK на Android-телефон і встановіть. Android може попросити дозволити встановлення з цього джерела.

Важливо:
- Це debug APK для особистого встановлення, не підписаний для Google Play.
- У цьому середовищі Android SDK/Gradle не встановлені, тому готовий APK тут не скомпільовано.
- Розрахунок за кількістю акумуляторів поки масштабує 117,27 Вт·год лінійно; це приблизна модель.
- ККД 85% — стартове припущення, його потрібно замінити виміряним значенням.
